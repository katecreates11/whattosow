# Dream — 15 August 2026 (week 5)

## What I found

A quiet week for decisions — one, card 21, and it had already happened
before this dream ran — but the loudest week yet for what was sitting
undiscovered. Local `git branch -r` after a fresh checkout only shows
`main`; it doesn't list remote branches unless you fetch them by name or
ask the GitHub API directly. This week's dream used the API's
`list_branches`/`list_pull_requests` instead, and found four stuck branches
and one long-open PR that a plain local check would have missed entirely —
which is very likely what happened last week too.

The result: two more Forager runs (2 and 9 August, seven cards total) never
reached `main`, the same pipeline bug that hit the 19 and 26 July runs.
Worse, it turns out the Groundskeeper and SEO Watchdog have *never* landed a
report on `main` — every single one, going back to early July, has sat on
its own branch. Last week's dream read that as three routines going quiet
in the same week Kate was busy elsewhere; the real explanation is
mechanical, not a coincidence of timing. See `wisdom.md` §1 and §5 for the
full correction.

Separately: the Glut-o-meter — approved 11 July, the crew's longest-pending
build, an open thread for four weeks running — has actually been built.
`night/glut-o-meter` (PR #3) opened 5 August and is sitting exactly where it
should: waiting for Kate's first review, which is the Night Gardener working
correctly, not stuck. But its one-open-PR-at-a-time rule means nothing else
can build while it waits, and it's been ten days. Eight approved,
build-ready cards (13, 14, 16–21) are frozen behind it.

consecutive weeks, and both times the honest answer was mechanical, not
human.** Two weeks ago: "a growing pile suppresses decisions" (wrong — Kate
was building the PR-repair fix). Last week: "three routines went quiet
together" (wrong — they were running, just landing on branches nobody
checked with the right tool). The pattern worth keeping: before writing "X
went quiet" into memory, check with the API, not just local git, and
default to a mechanical explanation before a behavioural one.

isn't code — it's Kate's next fifteen minutes at the Potting Bench reviewing
PR #3, which unblocks everything behind it at once.
