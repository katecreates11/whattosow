## Dreamt connections

**1. The site now has four confirmed instances of the same shape of
failure, each one level smaller than the last.** A live page can show
wrong copy (card 1), a live page can have no doors in (card 4), a whole
approved family can miss its season while queued (cards 8/12/16), and now
a single hand-written sentence on the homepage can sit five weeks out of
date. None of these are the same bug. All of them are the same root cause:
nothing revisits anything without a person spending a few minutes on it,
and those minutes haven't existed for ten weeks. The size of the thing
going stale is shrinking; the cause isn't changing.

**2. The relapse is better evidence than the clean run was.** A single
clean week could have been luck, a careful prompt, or genuine habit — no
way to tell from one data point. A clean week followed immediately by a
relapse into the exact old failure mode is much more informative: it says
the underlying tendency (branch from whatever's nearest, usually `main`)
is still the default, and the one clean run was the exception that needed
explaining, not the new normal. Worth remembering next time a single good
result shows up: ask what would have to be true for it to repeat, not just
whether it happened once.

**3. Independent convergence is now a reliable, low-cost signal across
four separate instances (leaf mould, top fruit, the bare-root family, and
now post-Halloween pumpkins) — and it's getting cheaper to use, not more
expensive.** Each time two crew members have named the same gap without
coordinating, folding them into one recommendation has taken a sentence,
not a new investigation. This is a genuinely bankable pattern: when it
happens again, look for it on sight rather than treating it as a surprise.
