## FIX NOW

Ranked by impact, most impactful first. Same ordering as the last several weeks — nothing has moved since `seo-2026-08-11.md` first set this list.

### 1. The entire `/sow-in` cluster — 52 pages — still has zero internal links from anywhere on the site
Re-checked in `src/app` this week: no `<Link>` to `/sow-in` or `/sow-in/[city]` outside the cluster's own pages and the header's search widget (which doesn't crawl as a link). **Fix:** one real link — from the homepage postcode tool or the header's location menu — clears all 52 at once.

### 2. `/still-time` and `/grow-your-christmas-dinner` are still orphans
Confirmed again this week (`grep` for both paths across `src/**/*.tsx` returns only each page's own file). **Fix:** link both from somewhere real — footer or a relevant guide.

### 3. `keywords` meta arrays still present — 55 files, 56 occurrences
Re-counted this week: `grep -rc "keywords:" src/app` → 55 files (one file, `blog/[slug]/page.tsx`, has 2). Includes the root `layout.tsx`, every guide, `/kit`, `/products`, `/bed-planner`, `/lucky-dip`, plus dynamic templates that multiply across crops, cities and blog posts. Google has ignored this tag since 2009 (`docs/CUT_LIST.md` already says so). **Fix:** still a one-shot mechanical cleanup — delete the field, no content change, no risk.

### 4. `/kit` canonical still points at `/guides`, not `/kit`
Re-verified in `src/app/kit/page.tsx:30` — `canonical: "/guides"`, with matching `openGraph.url`. Page is noindexed so zero live SERP cost today, but it's a landmine if noindex is ever lifted without someone re-checking this line. **Fix:** point it at `/kit`.

### 5. Titles run long across `/guides/*`, all 17 companion-planting topics, most editorial posts
Confirmed with two fresh examples this week: `/guides/growing-onions-garlic-leeks` — *"Growing Onions, Garlic & Leeks — The Allium Family (UK Guide) | What To Sow"* (76 characters), and the companion-planting carrot topic — *"Companion Plants for Carrots (UK) — Beat Carrot Fly Naturally | What To Sow"* (76 characters). Google's SERP typically truncates well before 70. Both titles are good copy that just needs 15-20 characters cut, most easily by dropping the trailing `| What To Sow` on the longest ones (the brand is already in the OG/site name). **Fix:** trim; start with the highest-traffic guides and the companion topics (17 pages, one shared template — `src/app/guides/companion-planting/[topic]/page.tsx` — so a length rule there fixes all 17 at once).

### 6. `/privacy` still missing from `sitemap.ts`
Re-checked: `grep "privacy" src/app/sitemap.ts` → no matches. The page itself is real, indexable and linked from the footer, but isn't in the sitemap Google is told to crawl from. Confirmed via `site:whattosow.co.uk privacy` this week too — no results (see INDEXING). **Fix:** add it to `sitemap.ts` — one line.

### 7. `/admin/photos` has no metadata export and isn't blocked in `robots.ts`
Re-verified: `src/app/admin/photos` has no `metadata` export at all (compare `src/app/bench/page.tsx`, which sets `robots: { index: false, follow: false }` on Kate's other private page). `src/app/robots.ts` only disallows AI-training bots by user-agent — it never disallows a path, so nothing stops Googlebot crawling `/admin/photos` if it's ever linked or guessed. Low real-world risk (it's an internal tool, presumably behind auth, and didn't surface in a `site:whattosow.co.uk admin` search this week), but it's a one-line, zero-risk fix sitting open for weeks. **Fix:** add the same `robots: { index: false, follow: false }` metadata export `/bench` already uses.

### 8. `/sow-in/[city]` title staleness — confirmed live again, now worse
`src/app/sow-in/[city]/page.tsx` computes the month name from `now.getMonth()` at build time, with no `revalidate` export. No rebuild has touched this route since June. A live search this week for `/sow-in/worcester` still returns Google's cached title as **"What to Sow in Worcester — June 2026."** It's now nearly September — over two months stale in the live SERP, and it will keep drifting by a further month every month `main` doesn't rebuild this route (see the cadence note at the top — that's now looking like a real, not hypothetical, risk). **Fix:** add `revalidate`, or better, drop the month/year from the title entirely — also shortens it, folding into fix #5 for this template.

### 9. `/guides/tomato-blight` and `/blight-watch` still compete for the same query
Unchanged, not urgent, worth a look when the blight guides get touched next.

### 10. Structured data gaps unchanged
Re-verified `src/app/guides/watering/page.tsx:66` — `FAQPage` schema only, no `Article`. Same pattern holds for `pests`, `soil`, `crop-rotation`, `growing-fruit`, `seed-starting`, `beginners` — 7 long-form guides total. All 181 variety pages still carry only `BreadcrumbList`. `frost-map` still has zero JSON-LD. Article schema is a real lever for these — it's what lets Google show a byline/date and be eligible for richer guide-type SERP treatment.

### 11. `/sow-in/[city]` thinness unchanged
No new measurement needed — no city-page content has changed since word counts were taken (26–47 words unique per page, ~35 avg). Still holding for the Search Console decision per `docs/CUT_LIST.md` §4.

## OPPORTUNITIES

Evidence-based, current UK gardening season (last week of August, moving into September). Cross-checked against `docs/ideas-board.md` first so nothing here duplicates a card already queued for the Forager/build pipeline.

1. **Spring bulbs (tulips, daffodils, crocus) — zero dedicated coverage on the site, and the buying window opens now.** UK bulb-planting season runs September–November (tulips specifically wait till after the first frosts, but daffodils and crocus go in from September). A `grep` for "bulb", "tulip", "daffodil", "crocus" across `src/app` found no dedicated guide or crop-style page — only incidental mentions inside unrelated guides. This is a real commercial-intent query window (bulb suppliers open autumn catalogues exactly like the site's own garlic/onion-set page already exploits — see `guides/autumn-planting-garlic-onions`, which is a good template for the tone) and it lines up with an already-recognised but unbuilt idea (`docs/dreams/wisdom.md` §1 references a "spring-bulb spacing" pitch, card 27, that fits the site's calculator DNA and hasn't been seen by Kate yet). Flagging as an SEO gap independent of that pitch: right now, the query has nowhere on the site to land at all.
2. **Hosepipe ban / drought coverage — still zero, still queued, worth one more mention.** Third week this has been checked (`site:whattosow.co.uk hosepipe` again returns nothing). Nine water companies now have active Temporary Use Bans, 71.3%+ of England remains in drought, 27m+ people restricted — England's driest July on record, still unresolved with no end date announced by any of the nine companies. This is already an approved, unbuilt content card (12/16 on the ideas board) — not re-pitching it, just noting the SEO gap is real and hasn't closed in three weeks of checking.
3. **Spring cabbage overwintering — near-miss, unchanged from last week.** Early-to-mid August is the sow-now window for spring cabbage overwintered as small plants for a March–May harvest, weeks ahead of any spring-sown crop. The `cabbage` entry in `src/data/crops.ts` still doesn't name this technique or list the actual overwintering cultivars people search for by name (Durham Early, April, Flower of Spring, Wintergreen) — it lists Hispi, January King, Red Drumhead instead. Window is closing as September approaches; still a small, well-scoped fix on a page that already ranks for "cabbage."
4. **Allium leaf miner / leek moth — near-miss, window opens within days.** The autumn danger period is September–November, essentially starting now. `growing-onions-garlic-leeks` mentions "allium leaf miner & onion fly" generically but not the September window or the mesh spec that actually matters (0.8mm fine mesh, not the coarser 1.3mm "fine" mesh commonly sold as insect-proof, which the RHS says isn't reliable against this pest). The `pests` guide still doesn't name allium leaf miner or leek moth at all despite being the page most likely to catch a generic search for it. Timeliness has increased since last week — this window opens imminently, not "in the next few weeks."
