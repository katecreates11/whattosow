## FIX NOW (most impactful first — all ten re-confirmed against the current files this week)

### 1. Homepage still ships two literal `<h1>` elements with identical text
**File:** `src/app/page.tsx:269` (mobile, `sm:hidden`) and `:299` (desktop, `hidden sm:flex`). Both render "Know exactly / what to plant, / right now" — a CSS show/hide, not conditional rendering, so Google sees two H1s on the site's highest-value URL. **Fix:** change one to a `<p>`/`<div>` with the same classes; no visual change. Fifth week flagging this.

### 2. `/kit`'s canonical and OG url still point at `/guides`
**File:** `src/app/kit/page.tsx:27` (`openGraph.url`) and `:30` (`alternates.canonical`) both still say `/guides`. The page is `robots: { index: false, follow: true }`, so crawl equity keeps leaking out under the wrong URL. **Fix:** point both at `/kit`, or drop the canonical since `noindex` already does the real work. Sixth week flagging this.

### 3. `/privacy` still isn't in the sitemap
**File:** `src/app/sitemap.ts`. Real metadata, its own canonical, linked from the footer — just missing from the static URL array. `/kit`, `/my-garden`, `/my-plot`, `/lucky-dip`, `/products` are deliberately excluded (there's a guard test); `/privacy` has no such exclusion, it's simply an omission. **Fix:** add one entry.

### 4. `/admin/photos` is still fully exposed with no metadata and no `noindex`
**File:** `src/app/admin/photos/page.tsx` — still no `metadata` export, so it inherits the homepage's title/description/canonical. `src/app/robots.ts` (re-read in full this week) blocks AI-training bots by name but has no `/admin` disallow rule for anyone else. Unlinked internally today, so low current risk, but zero actual barrier if the URL ever leaks. **Fix:** `metadata = { robots: { index: false, follow: false } }` at minimum.

### 5. Footer still has no link into `/sow-in`
**File:** `src/components/Footer.tsx` — still thirteen links across "Grow" and "Explore", none to `/sow-in`. The 51 city pages (sitemap priority 0.7) remain reachable only by direct URL. **Fix:** one footer link to `/sow-in`.

### 6. `/grow-your-christmas-dinner` is still orphaned — and its own planting window is now closing fast
**File:** `src/app/grow-your-christmas-dinner/page.tsx`. Re-confirmed by grep: only self-reference, the sitemap, and `seasonal-route-policy.ts` (config, not a link) mention this slug. ~1,200 words, FAQ schema, sitemap priority 0.8, a working tool — with no way in except a direct URL, four days before Halloween and deep into the window when "what can I still plant for Christmas" searches peak. **Fix:** one contextual link each from `/guides/autumn-winter-vegetables`, `/crops/brussels-sprouts`, `/crops/parsnips`, plus a homepage seasonal link through December. Then **[SC]** request indexing. Fifth week flagging this — the longest-running item on the list and one of the cheapest to fix.

### 7. Guide titles and descriptions remain systemically over-length
- **26 of 34** static `/guides/*` pages exceed ~60 characters, always because of the appended `` ` | What To Sow` `` suffix (15 chars) on an otherwise reasonable phrase. Worst: `/guides/growing-root-vegetables` at 79 chars (confirmed again: `"Growing Root Vegetables — Carrots, Beetroot, Parsnips & More (UK) | What To Sow"`).
- **17 of 17** `/guides/companion-planting/[topic]` pages exceed 60 chars once rendered — `page.tsx:76` appends the same suffix to `metaTitle` values that are fine on their own (50–62 chars).
- **17 of 17** companion-topic `description` fields in `src/data/companion-topics.ts` exceed 155 characters (worst: lettuce, 215 chars).
- **Fix (one change, two places):** drop the `| What To Sow` suffix on guide pages and the companion-topic template; trim the 17 companion descriptions to one sentence each.

### 8. `/sow-in/[city]` titles still bake in the current month/year at render time
**File:** `src/app/sow-in/[city]/page.tsx` (`revalidate = 3600`) — the indexed title changes every month ("...— October 2026 Sowing Guide" today, due to become "...— November 2026..." within days). Unnecessary re-crawl churn on 51 pages already on the CUT_LIST thin-content watch. **Fix:** a timeless title; keep month/year in body copy only.

### 9. `keywords` meta arrays remain in 57 files
Recounted this week, unchanged: 57 files, including `/kit` (item 2). Zero ranking impact per `docs/CUT_LIST.md`. Dead weight; worth a global strip whenever someone's next in these files.

### 10. `/crops` and `/sow` still carry no Article/CollectionPage schema
Both priority-0.9 — the two most important hub pages — still with no JSON-LD. Lower urgency than 1–6, but these are the pages most likely to earn rich results.

## OPPORTUNITIES (late October, UK)

### 1. "When to plant garlic UK" — sixth week flagging, window now more than half gone and closing further each week
Fresh search confirms the window again: RBGE and most UK sources call October–November the best slot (roots establish before hard frost); RHS gives October–December more loosely. `/guides/autumn-planting-garlic-onions` still titles itself "Order Garlic & Onion Sets Now — Autumn Planting UK" — ordering copy, not the planting-query phrasing people actually search — and still isn't surfaced in `guide-relevance.ts`, so it's absent from the site's own `/guides` index this month too. Same fix as the last five weeks, now with roughly one month of useful runway left before this becomes a "do it next October" item instead.

### 2. Halloween pumpkin seeds/carving — zero coverage, four days left, this is the last call
Re-confirmed: `src/app/guides/growing-squash-pumpkins-courgettes/page.tsx` has no mention of pumpkin seeds, carving, or Halloween at all (grep came back empty). "What to do with pumpkin seeds after carving" is a real, recurring UK search spike every year in the days around Halloween. A one-paragraph addition to an already-indexed, already-ranking page would catch it — but with Halloween on 31 October, this needs doing today or tomorrow to catch any of this year's spike; otherwise it's worth keeping on file to add properly before next October rather than rushing something thin.

### 3. "How to make leaf mould" — genuine near-miss, good runway, worth doing properly rather than fast
Re-confirmed: `/guides/composting` (`src/app/guides/composting/page.tsx`) still only mentions dry/autumn leaves as a generic brown input to hot composting — it has no section on leaf mould as its own, distinct process. Checked the two files that do say "leaf mould" (`guides/soil`, `guides/pests`) — both are passing mentions in other contexts, not a how-to. RHS and multiple UK sources (West Sussex County Council, Barton Grange) are actively serving this query right now: pile punctured bin bags of leaves, dampen if dry, 12–24 months to usable mould, oak/beech/hornbeam break down fastest. This is a November-peaking, multi-week-runway query, unlike #2 — the better use of any writing time this week.

- **Bare-root fruit tree season (November UK start)** — looked like a possible gap; it isn't. `src/app/guides/growing-fruit/page.tsx` already has solid, specific bare-root coverage (timing window, price comparison vs. container-grown, a full November–March planting table). No action needed.
