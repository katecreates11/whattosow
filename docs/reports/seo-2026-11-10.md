## FIX NOW (most impactful first — all re-confirmed against the current files this week)

### 1. `/grow-your-christmas-dinner` is still orphaned — Christmas is now 45 days out
**File:** `src/app/grow-your-christmas-dinner/page.tsx`. Re-confirmed by grep: still referenced only by itself, the sitemap, and `seasonal-route-policy.ts` (config, not a link) — zero inbound links from anywhere a reader would actually land. This is now the single most time-sensitive item in nine weeks of this report repeating it. **Fix:** one contextual link each from `/guides/autumn-winter-vegetables`, `/crops/parsnips`, `/crops/leeks`, plus a homepage seasonal link through 25 December. Then **[SC]** request indexing the day it's linked — every week of delay is a week of the highest-traffic window for this exact query going unclaimed.

### 2. Homepage still ships two literal `<h1>` elements with identical text
**File:** `src/app/page.tsx:269` (mobile, `sm:hidden`) and `:299` (desktop, `hidden sm:flex`). Both render "Know exactly / what to plant, / right now" via CSS show/hide rather than conditional rendering, so Google sees two H1s on the site's highest-value URL. **Fix:** change one to a `<p>`/`<div>` with the same classes — no visual change. Seventh week flagging this.

### 3. `/kit`'s canonical and OG url still point at `/guides`
**File:** `src/app/kit/page.tsx:27` (`openGraph.url`) and `:30` (`alternates.canonical`) — both still say `/guides`, confirmed by direct read. The page is `robots: { index: false, follow: true }`, so this is quietly leaking crawl signal to the wrong URL rather than causing a visible problem. **Fix:** point both at `/kit`, or drop the canonical since `noindex` already does the real work. Eighth week flagging this.

### 4. `/privacy` still isn't in the sitemap
**File:** `src/app/sitemap.ts` — read in full again, confirmed no `/privacy` entry in the static array. `/kit`, `/my-garden`, `/my-plot`, `/lucky-dip`, `/products` are deliberately excluded (there's a guard test for those); `/privacy` has no such exclusion, it's just missing. **Fix:** add one entry.

### 5. `/admin/photos` is still fully exposed with no metadata and no `noindex`
**File:** `src/app/admin/photos/page.tsx` is a client component (`"use client"`) with no `metadata` export, so it inherits the homepage's title/description/canonical. `src/app/robots.ts` (re-read in full) still only lists AI-training-bot disallows — no `/admin` rule for anyone. Unlinked internally today, so low current risk, but zero actual barrier if the URL leaks. **Fix, either is a one-line change:** add `disallow: "/admin"` to `robots.ts`, or wrap the page in a `layout.tsx` exporting `{ robots: { index: false, follow: false } }`.

## OPPORTUNITIES (mid-November, UK)

### 1. "How to force rhubarb" — still open, now the right week to act
Re-confirmed: `/crops/rhubarb` (`src/data/crops.ts:1225`) has only a one-line tip — "Force a clump in January for the most tender, pink stems" — plus variety notes that Timperley Early and Champagne "force" well. There is still no forcing how-to anywhere on the site (grepped "forc" across `src/`: only that tip and two variety notes). UK sources are consistent that forcing starts now, in November — covering a lifted or in-situ crown completely in darkness (an upturned pot, bucket, or forcing jar) so it thinks it's spring, with usable stems in 5–8 weeks. The site already recommends the two standard forcing varieties; it just doesn't explain the method. A short section on `/crops/rhubarb` — not a new page, this is exactly where the query belongs — covering what forcing is, when to start (now), and how, would catch real November search demand with content the page is one section away from already having. Third week this has been flagged; still no rush decision needed, but the window for "start now" framing narrows as the month goes on.

### 2. "How to make leaf mould" — still open, no rush
Re-confirmed: `/guides/composting` has no leaf-mould section at all — leaf mould is mentioned only on `/guides/soil` (as a soil amendment) and `/guides/pests`, never as its own slow-rot process with its own method (a bin bag with holes, or a wire cage, left 1–2 years). RHS and UK sources are actively serving this query through November as leaves keep falling. Carrying forward again — evidence unchanged, still weeks of runway left.
